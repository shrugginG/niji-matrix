# BATCH-TA0005-011 五技术整改研究与收敛约束

- 基线固定为 enterprise-attack 19.1；当前交付子集为 T1036、T1027、T1542、T1055、T1620。上一批 BATCH-TA0005-006 已通过证据、taxonomy、内容、防御、机器、Bundle 与 Web 门禁。
- 本批超过默认一至三个父候选，是延续用户明确要求的“五个匿迹技术一个批次”。五项候选分别保留独立证据查重、准入、taxonomy breadth、内容深度、防御、Bundle 与双语 Web 门禁；T1036、T1027 分别完成 12 与 18 项固定基线子项覆盖表和第二轮 taxonomy，不与三个复用候选共享结论。
- T1036 的直接对象是攻击者控制名称、位置、类型、签名或来源等可见特征，使防守方对对象身份或行为类型作出错误推断。原零子技术结论重新开放，至少比较资源身份拟态、类型呈现欺骗、执行谱系拟态和客户端特征拟态的痕迹与防御差异。
- T1027 的直接对象是让真实内容或语义在静态或常用表示中不可读，直到规范化、解码、解包、提取或运行时生成。原零子技术结论重新开放，至少比较可逆内容变换、结构与容量干扰、载体嵌入/走私和运行时生成的防御边界。
- T1542 是跨战术 NJT-0097 复用审查。固定基线五项 ATT&CK 实现只作广度输入，复核固件/启动链放置与外部启动源重定向两项既有变量，以及 Stealth 与 Persistence 的直接结果边界。
- T1055 是跨战术 NJT-0103 复用审查。固定基线十二项实现须映射到无文件映射、既有流调度替换、出生期映像来源分离和角色一致目标上下文四项变量；不为整改制造重复子技术。
- T1620 是跨战术 NJT-0077 复用审查。开放搜索复核既有进程中的模块载荷承载与反射式内存模块实例化两项变量，并与 NJT-0103 进程注入和普通共享模块加载保持边界。
- 所有新 REF、CLM、CASE、DET、NJA、MIT 先查共享库；正式 ID 在 taxonomy 与复用决议收敛后集中预留。候选数不保证新增父技术、子技术或共享对象数量。
- 当前五项全部通过结论级证据、字段深度、机器、Bundle 和双语 Web 门禁前，不进入下一批正式写入；TA0005 保持 active/in-progress。
