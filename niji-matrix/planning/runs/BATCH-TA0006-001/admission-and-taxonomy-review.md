# BATCH-TA0006-001 准入、分类与跨候选收敛

本记录在本批任何正式 NJT/NJS 与共享语义 ID 分配前完成。固定来源是 ATT&CK Enterprise 19.1 的 TA0006 与本地版本化工作簿；研究交接分别为 research-T1557.yaml 和 research-T1110.yaml。两个父候选均按其直接凭据获取行为接受，但以 Niji 匿迹结果重写范围，因此裁决为 adapt。ATT&CK 子项是广度先验，不作为 Niji 子项的分类标签。

## T1557：adapt，medium

正式父对象聚焦攻击者介入凭据承载的通信路径或认证证明的目标指向，使受害端继续面对可信或看似正常的路径，而攻击者得到可用的凭据材料或认证交换机会。纯网络转发、未触及认证材料的流量观察、服务拒绝和首次无线接入不因同属 AiTM 而成为 TA0006 结果。现有 NJS-0057-004 已涵盖钓鱼入口的实时 IdP/MFA 代理；TA0006 不以网页代理重新创建同义子项。T1040 的不改路被动嗅探、T1528/T1539 的已取得令牌或 Cookie 以及 T1689/T1600 的直接防护退化均按直接对象另行归属。

固定四项 ATT&CK 子项已逐项裁决：T1557.001 的名称伪答与 SMB relay 为两个不同 Niji 轴提供线索；T1557.002 是邻居路径实现，归父级；T1557.003 的 DHCPv6 主机过滤和短驻留支持选择性路径轴；T1557.004 是无线介质/接入身份实现，不自动构成独立子项。开放搜索还检验了实时 IdP 流连续性，但它由既有 NJS-0057-004 所有。

正式接受两项原生子技术。第一项“选择性信任指向替换”以受害主机/名称集合及路径驻留时间为受控变量，留下稀疏且短时的 DHCPv6、DNS 与终端目的地差分；mitm6 原作者文档直接证明该能力，真实告警降低未被测量，因此机理和匿迹收益只能按 hypothesis/low 表述。第二项“跨目标认证证明中继”以受害端期望目的地与实际验证目标之间的受众差为变量；原作者实验与 Microsoft SMB/LDAP 保护模型支持这一可实现链，服务端可能记录正常认证来源而受害端只见原目的地，置信度 medium。两项在所需数据、相关键与缓解动作上不同，不按 ARP/DHCP/无线或产品拆分。

## T1110：adapt，high

正式父对象是攻击者对未知秘密重复作候选验证，以得到可用秘密或缩小秘密空间，并通过控制时间、主体/来源拓扑或验证执行位置改变防守观察。普通用户误输、批准测试、账户恢复、材料取得、一次性使用已知有效秘密和后续资源访问都不满足该边界。在线失败事件不能证明同一口令被喷洒，离线哈希持有也不能自动证明已破解。

固定四项 ATT&CK 子项已逐项裁决：T1110.001 为在线节奏研究提供实现线索；T1110.002 为服务端外验证位置提供线索；T1110.003 为跨账户拓扑提供线索；T1110.004 的泄露凭据对首先是候选输入来源，只有出现独立节奏或拓扑差才进入某一 Niji 子项。这是覆盖而非翻译四种 ATT&CK 名称。

正式接受三项原生子技术。“时间展延式在线验证”控制可关联序列的时间密度，仍保留单次服务端事件，需要长窗口按身份重建；“跨主体与来源分布验证”控制账号、出口及应用之间的关联拓扑，需要跨源图连接与正常共享出口基线；“验证器脱离式候选测试”把候选判断移到攻击者控制域，服务端不产生逐次失败，防守只能核验验证材料取用、监控可见计算端或追踪后继认证。NIST 规范直接支持在线限速与离线恢复的观察差；CASE-000141 的 Volt Typhoon 事件明确记载材料复制和离线破解，可在不改变案例意义的前提下扩展适用主体。离线检测只能给出暴露与后继风险，不能把无失败日志断言成已经破解；这是正式 Analytic 的结果分级和盲区门槛。

## 跨技术与共享库裁决

T1557 介入认证承载路径；T1110 在未知秘密上反复验证。中间人获得握手、哈希或挑战可成为离线验证的前提，但两项行为、痕迹和结论应分开。T1003 拥有凭据材料转储，T1110 的离线子项只处理已得材料的后续候选比较。已有 NJS-0057-004、DET-000055、NJA-000125 与 MIT-000117 的入口/文档关系受控面不同，不作为本批路径介入防御的换名复用。

REF-000025、REF-000307、REF-000461 和 REF-000067 可在原有结论范围内复用；CASE-000141 可扩展主体，CASE-000172 仅是 Peach Sandstorm 后续订阅使用，不承载密码喷洒本体。Midnight Blizzard 和 Peach Sandstorm 的直接喷洒事实若进入案例库，必须分别建与现有案例不同的原子事件对象。两个父候选的策略目标、Analytic 数据与缓解控制面不同，防御对象分别创建；T1110 的两个在线子项可共用一项长窗口 Strategy，但使用独立 Analytic。T1557 的 CISA AA20-245A PDF 未完成原文复核，本批不将其作为正式来源或 Claim 依据。所有新来源以规范 URL、官方标识和语义逐项查重；交接临时键在主 Agent 收敛后才可替换为正式 ID。

正式内容必须逐字段对照 NJT-0001 的问题覆盖和论证深度。每个子技术的第一段匿迹特性以准确双语名称开头；不同候选不得复用通用威胁模型、相同限制或只替换名词的防御逻辑。人工领域评审尚未发生，全部正式对象只能进入 review。
