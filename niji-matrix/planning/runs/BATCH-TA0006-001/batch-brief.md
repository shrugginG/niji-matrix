# BATCH-TA0006-001 凭据获取首批研究与收敛约束

## 基线与范围

本批固定继承 matrix.yaml 的 MITRE ATT&CK Enterprise 19.1。planning/tactics/TA0006.yaml 和 program-inventory.md 已登记固定 TA0006 的 17 个父技术；当前正式 TA0006 矩阵为 0 项。本交付批次只处理 T1557 Adversary-in-the-Middle 与 T1110 Brute Force 两个父候选。二者分别作用于凭据承载流的信任路径与未知秘密的验证过程，直接对象不同，可以独立完成证据和双语内容审查。T1555 有六个 ATT&CK 子项，另作复杂单候选批。候选数不保证 NJT 或 NJS 数；本批所有候选通过证据、taxonomy、正文、防御、机器、Bundle 与双语 Web 门禁前，不开始下一批正式写入。

## 父技术边界

| 候选 | 直接行为与信息对象 | 与兄弟及既有技术的边界 |
|---|---|---|
| T1557 | 攻击者有意介入凭据承载的通信路径或名称、网关、无线接入信任指向，并由此取得认证材料或认证交换能力。 | 普通网络观测、未取得凭据的流量转发或单纯拒绝服务不足以完成 Credential Access；T1040 拥有不改变路径的被动嗅探，T1528/T1539 拥有所取令牌或 Cookie 的具体结果，T1689/T1600 拥有防御保护退化结果。 |
| T1110 | 对未知口令或已获哈希执行反复候选验证，以得到可用秘密或访问能力。 | 在线认证的服务端失败/成功序列与离线哈希破解的数据、时间和防守可见性不同；取得凭据后的正常会话属于后续访问，用户输错、授权安全测试及批量密码重置须由批准、目标、速率和结果排除。T1557 的路径操纵不是猜测。 |

## 子技术与证据门禁

T1557 在固定基线有 T1557.001、.002、.003、.004 四项，分别体现名称解析与 SMB relay、ARP、DHCP、无线伪接入点的实现差异；T1110 有 T1110.001、.002、.003、.004 四项，体现猜测、离线破解、喷洒和凭据填充的行为差异。每名研究者至少检查两个有实质区别的匿迹候选轴，逐项或逐簇作 parent-core、niji-variable-candidate、adjacent-technique、evidence-deferred 或 not-stealth-distinct 裁决。不能把协议、平台、密码攻击名称或 ATT&CK 子项直接变为 NJS。每个正式子项需有攻击者稳定可控变量、痕迹变化、防守观察差异、兄弟边界与独立防御价值。

固定 ATT&CK 父页只支持父行为和战术映射。优先使用一手事件调查、协议或平台官方文档与原始研究，把直接观察、推断、假设分开；公开或常见行为不能自动认定匿迹。T1557 的会话被介入事实不得自动证明密码、令牌或 Cookie 已获得；T1110 的失败日志不得自动证明秘密已破解，离线破解也不能臆造在线失败事件。按 NJT-0001 的字段责任审查完整双语自然段、残余可见性、攻击者前提、防守方遥测和结论级限制。

## 共享库与并行合同

研究前生成 catalog 并做精确重复审计，按标识符、URL 与语义指纹查询 REF、CLM、CASE、DET、NJA、MIT、REL。已存在的 Microsoft Peach Sandstorm 密码喷洒来源 REF-000461 可能与 T1110 相关，但须按原文事实复核；名称相似不足以复用共享对象。检测数据源、相关键、误报、盲区与调优必须可实施；Mitigation Application 应明确受控面、预期效果和限制，不能只替换候选名称。
