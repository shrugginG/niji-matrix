# BATCH-TA0006-003 准入、原生分类与跨技术收敛

固定 ATT&CK Enterprise 19.1。本批 T1212、T1187、T1606 均裁决 adapt，且在分配 ID 前完成跨五候选边界审查。

T1212 正式对象收窄为“脆弱凭据读取边界利用”：必须连接 exact vulnerable state、攻击者输入或读取、漏洞导致的边界跨越以及凭据材料或独立验证的读取能力。正式两项 NJS 按敏感存储侧 reader 划分为受害服务代理返回与低权上下文越界直读；产品、CVE 与漏洞类型不构成子项。UNC3886 事件只证明取得加密凭据和后继访问，不能宣称同一报告给出解密全过程。

T1187 正式对象为“诱发认证交换外发”：区分诱因/调用、外连、挑战响应到达、后继中继与离线破解。正式两项 NJS 分别由后台资源解析与远程服务调用构成；文档、图标、UNC、SMB/WebDAV、EFSRPC 都是实现。文档子集复用既有 NJT-0119/DET-000116/NJA-000125/MIT-000117，通用父级仍需自己的路径关联。后继受众中继归 NJT-0136，离线候选验证归 NJT-0137。

T1606 正式对象为“离权威 Web 认证材料构造”：只包括攻击者在正规签发链之外新构造材料，排除 AWS STS 等权威 API 按策略正常签发。正式两项 NJS 是签发链外可信证明铸造与组合认证辅状态伪造；Cookie/SAML 只作实现广度。Storm-0558 和 Dark Halo/Duo 分别支持完整证明与辅助状态轴。新增 signer/trust 属 T1556/NJT-0093 状态变化，可与实际材料构造并列；材料盗取归 T1539/T1528，使用归 Valid Accounts。

跨候选边界：T1187 产生受害端认证交换，T1606 自行构造新的 Web 证明；T1212 必须由漏洞直接导致材料或读取边界跨越。T1187 的真实系统认证提示不同于 T1056 的仿冒消费者输入；T1056 真消费者镜像与 T1556 旁路复制的区别是后者需要认证过程被持久或可重复改变。三个候选均完整双语对照 NJT-0001，正式防御按各自因果、数据和控制面拆分，不共享换名 Analytic。
