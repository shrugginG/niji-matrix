# BATCH-TA0006-003 T1212、T1187、T1606 研究与收敛

## 总体范围与门禁

本轮总体开发范围是 TA0006 固定清单中的下五项：T1212、T1187、T1606、T1056、T1556。为满足候选级质量门禁，正式交付沿用规划中的 3+1+1：本批只正式集成前三项；T1056 与 T1556 可并行研究，但分别在 BATCH-TA0006-004/005 通过独立门禁后才能写入。上一批 T1555 已通过 make quality、Bundle、91 项 Web 测试与 API QA并处于 review。所有范围均固定 ATT&CK Enterprise 19.1；五项研究分两轮 sub-agent，主 Agent 等全部交接后统一做跨技术边界和共享库决议。

## 候选边界

- T1212 Exploitation for Credential Access：直接对象是漏洞触发后得到凭据、认证材料或读取能力的因果结果。仅代码执行、提权或防御绕过分别归相关技术；漏洞存在、崩溃或 PoC 不证明凭据已获。与 T1003/T1555 以“漏洞是否是直接取密机制”划界，与 T1211 一般匿迹利用和 TA0112 防御损伤分开。固定子项 0，仍需开放搜索输入选择、目标状态、结果反馈或其他稳定观察轴。
- T1187 Forced Authentication：直接对象是诱使或强制受害主体/设备向攻击者可观察的目标发出认证交换，从而取得挑战响应或等价材料。文档模板、图片、UNC 路径与协议仅为诱因/载体；T1557 拥有路径介入，T1110/NJS-0137-003 拥有后续候选验证，T1221/NJT-0119 拥有文档引用入口的载体变量。必须区分“认证被触发”“材料被攻击者观察”“后续中继或破解”。
- T1606 Forge Web Credentials：直接对象是攻击者构造可被 Web/联合身份依赖方接受的认证声明或会话材料。固定 T1606.001 Web Cookies 与 .002 SAML Tokens 只作实现广度，不能直接复制。与 T1539 盗取既有 Cookie、T1528 盗取访问令牌、T1558 Kerberos 票据伪造、T1556 修改验证过程及 Valid Accounts 实际使用划界。开放搜索签名/签发权、声明或会话状态、时间/受众绑定及防守可观察差异。

## 分类、证据与共享库

每项先给 retain/adapt/exclude。ATT&CK 父页只锚定父行为和战术；NJS 要求攻击者控制变量、前后痕迹、防守观察差、兄弟边界和独立防御价值。公开实验、漏洞说明与能力文档不能自动升级为在野成功案例。研究者查询全局 REF/CLM/CASE/DET/NJA/MIT/REL，使用 TA0006-003-<ATTACK-ID> 临时键，只写本目录 research-<ATTACK-ID>.yaml，不分配 ID、不修改正式矩阵、计划或共享库。检测须给实际数据字段、相关窗口、误报、盲区与调优；缓解须有目标特定 Application。完整双语稿对照 NJT-0001 的字段责任与论证深度。
