# BATCH-TA0006-004 T1056 准入与原生分类裁决

T1056 裁决 adapt，父级为“认证输入路径截获”。固定四项 ATT&CK 子项已逐项覆盖，但不按 Keylogging、GUI、Web Portal、API Hooking 复制。正式三项 NJS：消费者前输入流旁路、真实消费者内提交镜像、仿冒消费者诱导取密。它们分别改变应用解析前的传感面、真实登录消费者内部的提交副本、以及用户所见消费者与真正接收者的身份关系，数据、正常反例和缓解不同。

窗口或页面门控由既有 NJS-0132-001 拥有；缓存、加密与分批输出属于后继处理或证据不足假设。屏幕像素、浏览器已显示内容、音视频、存储凭据及提交后的令牌/会话各归相邻对象。真实平台认证提示诱发向外发送材料可与 T1187 并列，但纯仿冒 UI 属本项；T1556 的旁路复制还要求认证过程本身被改变并可跨事务工作。
