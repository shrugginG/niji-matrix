# BATCH-TA0006-005 T1556 跨战术复用与第二轮 taxonomy 裁决

TA0006 对 T1556 裁决 adapt，正式对象决议为 reuse-and-extend NJT-0093，禁止复制父技术。父级增加 TA0006 tactic_ref，并将名称、定义、场景、机理、边界、防御和证据扩为同时表达持久异常允许与认证路径内秘密获取；TA0003 的 DEC 保持独立，TA0006 新建独立 DEC。

九项固定 ATT&CK 子项完成逐项覆盖和第二轮搜索。现有 NJS-0093-001 继续拥有选择性后门证明允许，NJS-0093-002 继续拥有范围化策略例外；两者不因 TA0006 映射改成凭据获取。正式新增一项 parent-scoped NJS：“认证事务内秘密旁路复制”，要求修改后的密码过滤器、Network Provider、PAM、PTA 或等价认证路径在正常认证同时产生秘密副本或可验证输出，和 T1056 单次输入截获以可重复认证组件状态划界。

“策略诱导的未来秘密可恢复化”本轮 defer。可逆加密策略与事件审计证明未来材料可能可恢复，但缺少同一在野事件的策略变更、密码变化、材料生成、恢复和攻击者取得完整链，不能以产品能力补齐。若未来取得该链，重新审查第二项。Credential Access 专属新 DET/NJA/MIT 只覆盖秘密输出子项；既有 DET-000073/NJA-000052/MIT-000073 保持异常允许的 Persistence 身份，并由扩展父级同时引用。
