# BATCH-TA0006-006 准入、原生分类与边界裁决

## T1111

裁决 `adapt`，正式父义为“多因素认证证明截获 / Multi-Factor Authentication Proof Interception”。完成点要求 MFA 证明或能够持续生成证明的状态实际进入攻击者控制面；可查看能力、投递、读取尝试、验证接受和后继登录分层。

正式 NJS：

1. 短时单次证明截获：取得仍有效、尚未消费的具体证明；以签发—读取—消费主体差和短寿命为稳定变量。
2. 认证证明生成状态复制：取得软件认证器 seed/container 等长期状态并恢复未来证明生成；正式置信度为 medium，保留 Operation Wocao 对攻击者实际取得与研究者“最可能实现路径”的区分。

“驻留绑定认证器代理”暂缓。Sykipot 只证明智能卡代理能力，缺少同一在野事件中未导出秘密、持续调用绑定认证器、证明被目标接受和后继结果的完整链。

T1111 只拥有 MFA 材料结果。仿冒输入面或输入事件由 NJT-0169 拥有，认证组件第二输出由 NJS-0093-003 拥有，AiTM 中继由 NJT-0136 拥有，系统诱发证明外发由 NJT-0165 拥有；各对象只有在自身直接证据成立时并列。

## T1621

裁决 `adapt`，正式父义为“攻击者驱动的多因素认证挑战生成 / Adversary-Driven Multi-Factor Authentication Challenge Generation”。challenge 创建、投递、用户响应、token/session 和资源访问保持独立阶段；批准或资源访问不是父级成立的必要条件。

正式 NJS：

1. 受信挑战重复压力：由真实 IdP 反复生成独立 challenge，单次事件保持权威 issuer 外观，异常存在于跨事务节奏、来源和用户意图；“高频”本身不是 NM-ST。
2. 跨信道请求情境同步：外部支持/安保叙事与真实 challenge 在时间和应用上同步，通信面与身份面分离；语音、Teams、邮件和厂商不构成分类。

T1621 只拥有攻击者发起的权威 challenge。证明材料被截获归 T1111，输入被仿冒面接收归 NJT-0169，帮助台身份冒充但没有 MFA challenge 归 NJT-0118，账户认证器新增归 NJT-0083，策略绕过归 NJT-0093/TA0112，后继访问归 NJT-0061。
