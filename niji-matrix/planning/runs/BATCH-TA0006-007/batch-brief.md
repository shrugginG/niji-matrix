# BATCH-TA0006-007 T1040 研究与收敛约束

本批正式处理 TA0006 固定清单第 11 项 T1040 Network Sniffing，基线固定 ATT&CK Enterprise 19.1。研究需区分被动网络观察、镜像或中间路径控制、加密边界与实际凭据材料结果，并与 NJT-0136/T1557、T1187、T1111 以及一般网络发现边界化。

sub-agent 只提交研究交接，不分配 ID，不修改正式矩阵或共享库。Niji 子项只能来自稳定的观察位置、痕迹拓扑和防守数据差异；网络接口、工具、协议名、云或本地环境不是兄弟分类。主 Agent 等五份结果齐全并完成统一边界裁决后才正式写入，本批需独立通过质量、Bundle 与 Web 门禁。
