# BATCH-TA0006-008 T1003 准入、八项覆盖与第二轮分类裁决

T1003 裁决 `adapt`，正式父义为“操作系统认证材料提取 / Operating-System Authentication-Material Extraction”。权限、对象打开、读取、材料复制、依赖解锁或解析、输出和后继使用保持独立阶段。

固定八项 ATT&CK 子技术已逐项覆盖材料位置、保护面、读取主体、活动/副本/服务状态、依赖、审计面和结果门槛。第二轮删除 LSASS、SAM、NTDS、LSA、DCSync、proc、passwd/shadow 等实现名称，收敛为三项 Niji 原生变量：

1. 可信凭据读取上下文转用：读取代码进入本来就接近目标材料的受信进程、服务或工具，改变 reader provenance。
2. 非活动认证存储视图提取：从快照、备份、原始派生或其他非活动视图取出认证存储，离开活动对象锁和文件审计；可与 NJT-0108 的替代存储介质路径并列，但结果和介质证据不可互相替代。
3. 目录复制式认证材料导出：使用合法目录复制控制面让权威服务返回秘密，观察键转为 caller/host/rights/naming-context/response；DCSync 只是实现名称。

普通高权进程直接读取活动存储保留为父级核心。运行态/静态位置、材料类别、操作系统、低量账户范围、dump 加密和后继离线猜测不建子项；离线候选比较归 NJS-0137-003。

目录复制子项保留现场案例不足限制：协议规范、官方检测语义和受控实验可证明控制面与结果能力，但正式案例不得把 RPC 连接或单一告警写成全域散列已取得。

共享库复用或扩展 REF-000025/366/367/379/749/750、CLM-000588/589/704、CASE-000134/141、DET-000105/NJA-000090、MIT-000107/134；新增对象只承载无法由现有替代存储视图、防御或离线验证对象表达的 OS 材料结果和 reader/replication 差异。
