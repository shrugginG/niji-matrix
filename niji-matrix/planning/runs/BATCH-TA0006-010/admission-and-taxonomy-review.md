## 固定广度与两轮原生分类

19.1 T1649 的 ATT&CK 子项数量 0、ID 清单 []，普通广度触发。第一轮覆盖既有终端私钥取得、正常服务中的恶意签发、服务外受信签名、不可导出密钥调用。第二轮按去产品/去工具后的可控变量、痕迹变化、观察影响和防御差异复核。

| 研究轴 | 决议 | 理由与观察差异 |
|---|---|---|
| 既有终端私钥取得 | parent-core | 私钥结果必须证明；按文件、库、内存、DPAPI 拆分会复刻 NJT-0147/0177/T1552，尚无独立匿迹分类必要 |
| 受信签发上下文挟持 | formal NJS | 攻击控制者与服务所信任的请求身份/代理范围/组织意图脱节；正常 CA 签发记录仍在，需授权与来源关联 |
| 脱离签发链的认证证书构造 | formal NJS | 已受信签名能力在权威服务外形成新证书；接受端与完整签发库存差分，缺失本身不证明伪造 |
| 不可导出密钥本地/远程调用 | evidence-deferred | 只有平台能力与控制原理，缺独立取得、攻击实践和匿迹效应证据 |
| 有效期、字段、频率及产品/工具/ESC 编号 | not-stealth-distinct / evidence-deferred | 前者缺结论层级支持，后者为实现标签；均不直接成子项 |

正式 2 NJS，来源于独立稳定变量。父级核心可以有未单独分类的已有私钥取得路径；不声称两项穷尽所有实现。S1 的实际签发滥用有真实事件支持；S2 主要为原始实现和实验支持，在野 case 留空。两项机理置信度 medium；不声称普遍无告警。NM-FD 与 NM-BT 成立；未证明时间/来源稀释的 NM-ST，加密保护容器也不自动成为 NM-DO。

## 边界

NJT-0147 拥有受管理库的解锁与返回；NJT-0177 拥有 OS 认证秘密；T1552 拥有未保护秘密暴露，均不可从路径或读取事件反推证书私钥已取。NJT-0178 取得应用令牌；NJT-0166 构造 Web/联合材料，AD FS signing-key 与 Golden SAML 不充当客户端证书子项证据。NJT-0093/0100 处理认证路径/信任修改，NJT-0083 处理账户认证器增补，NJT-0173 处理对象信任输入；这些状态变化不自动证明凭据结果。NJT-0061/T1550 的身份/材料使用、T1558 票据窃取/伪造均与本批分阶段。KDC 正常 PKINIT 签发 TGT 不能改写成票据伪造。TA0011 已闭合计划只作为 C2 边界依据，不修改它。
