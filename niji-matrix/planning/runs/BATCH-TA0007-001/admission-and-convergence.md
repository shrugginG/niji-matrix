# BATCH-TA0007-001 准入与跨技术收敛

主审在阅读 T1087 与 T1010 两份独立交接后作出下列准入判断；本记录先于任何 NJT/NJS 或共享库 ID 分配。固定清单来源为本地 ATT&CK Enterprise 19.1 技术表，候选顺序和子项广度见 `program-inventory.md`。

## T1087：adapt，medium

保留“取得环境中既有账户标识及清单”的父行为，将 Niji 范围限定为攻击者主动选择的获取路径在权威查询面与端点既存视图之间产生可说明的观察差。Oldrea 取用 Outlook 地址簿是直接案例事实；Microsoft 文档证实 OAB 可在端点保存并离线使用。由两者推得“本次取名单可能不产生即时目录查询”是架构推断，不能写成 Oldrea 已被取证证明读取 OAB 文件，或其明确为避开目录审计而行动。父级和拟议子项可按此条件性机制入库，置信度维持 medium，研究限制必须醒目。若后续领域评审要求同案 OAB 文件与目录缺席的直接取证，应把该子项退回 draft/deferred。

四个 ATT&CK 子项按本地、域、邮件、云账户的实现面划分；只有“既存身份视图复用”跨介质构成目前可成立的 Niji 变量。低频查询和借常规客户端查询缺少意图与独立痕迹证据，暂缓。T1069 管组和授权关系，T1033 管特定系统的当前用户，T1136 管账户新建，T1078 管凭据使用，NJT-0033 管获得内部访问前的身份资料；它们的结果不自动成为 T1087 子项。

## T1010：retain，medium

保留“读取开放窗口、标题和前台上下文”的父行为。ESET 对 Grandoreiro 的分析直接记录窗口标题条件命中后才启动频繁 C2；Attor 的目标选择同时使用进程名与窗口标题。窗口状态是发现对象，后继网络或截图只是证明条件性结果，不改变后继行为各自的技术归属。正式子项以“窗口上下文门控后继活动”的受控谓词及命中前后痕迹差界定；不把进程名谓词、单次前台查询或辅助功能接口直接复制成子项。

T1057 管进程清单，T1518 管已安装软件，T1497 管把环境信号用于沙箱判断。普通无障碍、桌面自动化和窗口管理是强反例。标准 Sysmon Event 10 不能当作 EnumWindows 事件；Analytic 需要先部署且验证 GUI 调用或窗口状态传感器，缺失时只能给低置信的间接链。

## 共享库与相互边界

两个候选的信息对象、痕迹和防御数据模型不同，不合并父技术、子技术、DET、NJA 或 MIT。T1087 需要身份材料读取、目录查询和端点文件/客户端谱系；T1010 需要交互会话、窗口状态和后继网络或收集结果的因果链。REF-000366（Sysmon 事件）和 REF-000379（Windows 4663）可按精确语义复用，既有 DET-000033 身份工作流响应差异不能扩充为内部账户清单读取。Grandoreiro、Attor、Oldrea 事件分别建各自事实边界；不从案例推断检测成功率。

准入不预设“必须有两个子项”。本轮各提议一个原生子项，均基于受控变量和残余痕迹，而非 ATT&CK 子项名称。正式内容与防御对象完成后仍须逐对象比较 NJT-0001 字段责任、自然双语论证及结论级证据。
