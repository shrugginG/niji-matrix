# TA0009 首批准入与跨技术收敛

基线为 ATT&CK Enterprise 19.1。主 Agent 在三份独立研究交接完成后作如下准入裁决；裁决早于正式 ID 分配。

| 候选 | 准入 | 正式 Niji 子项 | 暂缓或排除的轴 |
|---|---|---|---|
| T1560 | retain | 受保护归档内容遮蔽；进程内归档谱系压缩 | 分卷主要属于传输分块/大小管理，缺少独立匿迹效果证据；改名 `init.dat` 与既有外观伪装边界重合，原始报告未验证检测差异。 |
| T1074 | adapt 为匿迹型数据暂存 | 出口汇聚暂存 | 低审查命名空间暂存当前与 NJS-0114-001 的可信路径身份拟态及工件可见性边界有重叠，公开案例证明落点而未证明独立的规则漏判或匿迹意图；注册表缓冲与 NJS-0115-003 边界尚未收敛。 |
| T1119 | adapt 为匿迹约束的自动收集 | 变化检查点约束的增量收集 | 来源到达触发、工作流触发、固定周期与扩展名筛选只证明自动化或目标选择，当前不足以证明独立匿迹差异。 |

T1560 的直接对象是已取得数据到归档容器或编码流的转换；T1074 是数据的中间汇聚拓扑；T1119 是可重复执行的数据获取规则。一个事件可以共映射，但归档格式、暂存目录和定时任务不能互为证据。T1560 的口令保护可能同时涉及 NJT-0115 的内容表示遮蔽，但 Collection 子项只讨论已收集数据的归档、源到产物及外传关系，不能从高熵或加密单独推断数据窃取。T1074 的出口汇聚以多源到少数外联节点的拓扑关系为边界，不按 ATT&CK 的本地/远程子项划分。T1119 增量收集以跨轮检查点缩小后续读取集合为边界，不能由周期调度或文件类型过滤替代。

证据强度分层：ATT&CK 固定版支撑父行为与战术映射；事件与逆向报告支撑现场实施；产品文档支撑可获得的遥测字段。InvisiMole 的内部 Zlib 路径直接支撑“无独立归档工具进程”的实现可能，但不证明全部文件无落盘输出；FunnyDream FilePakMonitor 的检查点与变化文件选择有直接逆向证据，降低短窗口信号属于条件推断。正式内容应保留这些限制，且不得把案例的父级行为升级为未观察到的子项。

此批正式输出目标为 3 个 NJT 与 4 个 NJS。五项 ATT&CK 子项（T1560 的 3 项、T1074 的 2 项）仅记录在研究覆盖表，T1119 无 ATT&CK 子项仍做开放式轴搜索。所有 NJS 均按可控匿迹变量和防守观察差异定义，`lineage.attck_subtechnique_inherited` 为 `false`。
