## 跨技术归属

- T1025 的完成点是当前可移动介质返回内容。T1091/NJT-0058 负责恶意内容随介质进入另一主机并触发，T1005/NJT-0215 负责正常导入后的本地副本，NJT-0194 负责数据写入介质并离域，NJT-0207 负责介质命令—结果闭环，NJT-0108 负责原始卷和普通文件命名空间外的读取。
- 介质接入触发扫描、自动选择、轮询或检查点由 T1119/NJT-0135 表达；暂存、归档和内部传递分别属于 NJT-0134、NJT-0133 和 NJT-0130。它们可与 T1025 同现，但不成为 T1025 子项。
- 新 T1056 Collection 对象排除认证秘密；只在普通文本、支付字段、业务数据或其他非认证输入实际进入攻击者缓冲、文件、请求或传输链时成立。认证秘密仍归 NJT-0169；同案只有在两类结果分别有证据时双标。
- 剪贴板服务已经提供的内容归 NJT-0214；浏览器已显示或返回的页面内容归 NJT-0145；进程注入、表单资产改写、社会工程入口、暂存和外传是前置、伴随或后继行为，不能替代输入结果。

## 共享库决议

- T1025 复用 REF-000914、REF-000597、REF-001070、REF-000379；扩展 REF-001077 与 REF-000906 的精确 locator。REF-000512、REF-000596、CASE-000184、CASE-000277、CASE-000299 只作边界对象。
- T1056 复用 REF-000728、CASE-000235、DET-000192、NJA-000215 和 MIT-000173；同一 DRBControl 事件只扩展现有 Case 的 subject，不创建第二个事件。消费者外分支精确扩展既有 Detection 与 Mitigation，受信数据入口分支新建表单资产—接收者—结果专用防御。
- T1025 新建父级介质读取结果 Detection、两个可实施 Analytic 和一个读取授权/对象谱系 Mitigation；跨接入 Analytic 可用于父级调查，但不把 deferred 假设转为正式 NJS。
- T1056 固定四个 ATT&CK 子项只作 planning 覆盖；Keylogging、GUI Input Capture、Web Portal Capture 与 Credential API Hooking 均不直接导入。
