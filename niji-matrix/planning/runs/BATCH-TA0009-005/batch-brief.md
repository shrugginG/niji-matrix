# BATCH-TA0009-005 最终批简报

本批只处理 TA0009 固定 ATT&CK Enterprise 19.1 清单中尚未进入正式矩阵的两个父候选：T1025 Data from Removable Media 与 T1056 Input Capture。批次完成后应以 TA0009 正式矩阵父技术 17/17 为闭合条件，不引用 TA0005 或外部候选数。

两名 sub-agent 各研究一个父候选，只提交证据、准入建议、Niji 原生分类和防御方案。sub-agent 不分配正式 ID，不修改正式矩阵、共享库、战术计划或 ID registry。主 Agent 等两份交接全部完成后统一处理跨技术边界、共享库查重、正式写入、质量、Bundle 与 Web 验收。

## 重点边界

- T1025 必须证明从可移动介质实际取得内容；介质出现、挂载、卷枚举、文件名发现、恶意程序从介质执行、后继暂存或外传均不能代替内容读取结果。重点核对 T1091、T1005、T1074、T1119、T1570 与 TA0010。
- T1056 必须先审查现有 NJT-0169 及 NJS-0169-001..003 的跨战术所有权。若同一直接对象、变量与防御已由 TA0006 正式对象完整表达，应复用并增加独立 TA0009 决议；若 Collection 存在超出认证输入的稳定直接对象，必须另证内容结果、匿迹变量与观察差，不能为完成计数而复制父技术。
- 固定 ATT&CK 子项仅作为研究覆盖：T1025 无子项；T1056 有 T1056.004、T1056.002、T1056.001、T1056.003。任何正式 NJS 均须重新按 Niji 变量分类。

## 完成门

两候选先完成 retain、adapt 或 exclude 准入。正式对象须完整双语覆盖定义、匿迹特性、范围、场景、攻防模型、机理、证据和研究限制，并具备可实施 DET/NJA/MIT 或经证明的精确复用。全库查重、ID 同步、`make quality`、Bundle、Web 全量测试与双语 API QA 通过后提升为 `review`；人工领域评审前不发布。
