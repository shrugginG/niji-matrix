# BATCH-TA0010-001 研究与收敛约束

## 基线与范围

- 战术：TA0010 Exfiltration（数据渗出）。
- ATT&CK domain/version：enterprise-attack 19.1；九个父候选见同目录 `program-inventory.md`。
- 当前交付批次：T1030 Data Transfer Size Limits、T1029 Scheduled Transfer。两个候选分别控制传输规模和传输时机，适合并行查证后统一处理交叉边界；每项单独通过证据、内容和防御门禁。
- 前一批次：无。TA0010 当前没有正式技术。本批通过全部门禁前，不开始下一批正式写入。
- 候选数不预设正式 NJT/NJS 数量；`exclude` 只留下准入决策。未完成人工领域评审时保持 `review`。

## 父技术边界

| 候选 | 直接行为对象 | 兄弟及相邻边界 |
|---|---|---|
| T1030 | 单次、单文件或单位时间外传规模的攻击者控制，包括切块和带宽限制 | T1029 控制何时发生传输；T1020 控制自动触发与处理；T1048/T1041/T1567 控制通道或服务；TA0009 T1560 控制传输前归档，T1074 控制暂存 |
| T1029 | 外传发生的时刻、周期或与正常业务窗口的时间关系 | T1030 控制规模；T1020 的自动化未必有隐蔽时序；T1041 等通道候选不因定时而改变归属 |

## 子技术与证据规则

- 两个候选在 ATT&CK 19.1 中均无子项；仍须开放搜索 Niji 原生匿迹变量。不能把切块或定时的实现工具当成分类本身。
- 每一提议子项须有稳定的攻击者可控变量、行为→痕迹→防守观察差异→匿迹效果的因果链，以及与兄弟项不同的检测或缓解价值。
- ATT&CK 父页面仅证明父行为和战术映射。案例、机理、子项、检测字段与缓解作用均需结论级来源；不足时降低置信度或暂缓。
- 正式双语父子字段逐项对照 NJT-0001 的责任和论证深度，检查重复正文、通用威胁模型、同文限制。

- 研究前查 `make catalog`、`audit_duplicates.py` 与 `library_lookup.py`；已有来源或对象只在语义完全一致时复用。
- 两名 sub-agent 各研究一个父候选；T1030 使用 `B10-T1030-*` 临时键，T1029 使用 `B10-T1029-*`。交接文件只放本批次目录，均不得分配正式 ID、修改正式矩阵或共享库。
- 主 Agent 等待两份交接后，统一决议边界、共享库、ID、双语正式稿及验收。脚本只承担分配、序列化与校验，不批量生成读者正文。
- 重点核对 T1030 的速率限制是否实际属于大小控制，及 T1029 的周期性是否只是 T1020 自动化的结果；无匿迹因果的普通调度和带宽管理不准入。
