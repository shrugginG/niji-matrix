# BATCH-TA0010-002 研究与收敛约束

## 基线与范围

- 战术：TA0010 Exfiltration（数据渗出）。
- ATT&CK domain/version：enterprise-attack 19.1；总体范围固定为 TA0010 的九个父候选。
- 当前交付批次：T1020 Automated Exfiltration、T1048 Exfiltration Over Alternative Protocol、T1041 Exfiltration Over C2 Channel、T1011 Exfiltration Over Other Network Medium、T1052 Exfiltration Over Physical Medium。
- 用户要求本批处理五项，研究分两轮完成：第一轮 T1020、T1048、T1041，第二轮 T1011、T1052。每个候选独立通过准入、证据、分类、内容和防御门禁；不得因并行或同批收敛而降低逐候选标准。
- 前批 BATCH-TA0010-001 的 review 门禁已经通过。本批完成统一集成前不得开始 T1567 Exfiltration Over Web Service 或 T1537 Transfer Data to Cloud Account。
- 候选数不预设正式 NJT/NJS 数量；`exclude` 只留下准入决策。未完成人工领域评审时保持 `review`。

## 父技术边界

| 候选 | 直接行为对象 | 本批边界 |
|---|---|---|
| T1020 | 外传流程的自动选择、触发、处理或转发 | 自动化本身不决定协议、C2 关系、网络介质或物理介质；仅有普通调度不足以证明匿迹差异 |
| T1048 | 通过不同于既有 C2 通道的替代协议外传 | 协议选择与承载形态属于本候选；复用既有 C2 关系归 T1041，其他网络介质归 T1011，物理介质归 T1052 |
| T1041 | 复用已经建立的命令与控制关系输送外传数据 | 核心变量是通道关系复用及其归因、关联或可区分性影响；数据编码、协议替代、Web 服务实现及 TA0011 的 C2 匿迹对象需分别划界 |
| T1011 | 通过主要企业网络之外的其他网络介质外传 | 区分媒介路径与协议替代；通过可移动物理介质转移归 T1052 |
| T1052 | 通过物理介质承载外传数据 | 核心是物理转移及设备生命周期；联网旁路介质归 T1011 |

## 子技术与证据规则

- ATT&CK 子技术仅作研究和分类广度先验，不得直接复制、翻译、合并或改名为 Niji 子技术。每一 NJS 必须由稳定的攻击者可控匿迹变量、痕迹变化、防守观察差异和有用的检测或缓解差异共同支持。
- T1048 必须检查至少两条实质不同的候选匿迹轴，并按固定基线的 ATT&CK 子项完成覆盖解析；其他候选即使无 ATT&CK 子项也必须开放搜索 Niji 原生匿迹变量。
- 每项先做 `retain`、`adapt` 或 `exclude` 准入判断，再提出正式内容。ATT&CK 父页面只能锚定父行为和战术映射；案例、机理、子项、Detection Strategy、Detection Analytic 和 Mitigation 均需结论级证据。
- 父子双语框架须逐字段对照 NJT-0001 的责任与论证深度，覆盖定义、匿迹特性、范围边界、应用场景、攻防模型、匿迹机理、证据与研究限制。
