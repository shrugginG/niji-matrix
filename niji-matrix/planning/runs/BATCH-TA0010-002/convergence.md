# BATCH-TA0010-002 主 Agent 五候选收敛

五份 sub-agent 交接全部完成并通过 YAML 解析后，主 Agent 才进行本决议。ATT&CK 19.1 子技术仅作广度先验；正式 NJS 按稳定变量、痕迹变化和防守观察差异建立。

## 准入

- T1020：adapt。自动化只有在改变生产者—外送者谱系或把复制痕迹移到控制面时进入 Niji；普通脚本和定时上传不因自动化本身准入。
- T1048：retain。保留相对既有 C2 使用不同协议/接收路径的父语义；三个 ATT&CK 加密子项不继承。
- T1041：adapt。限定为失窃数据复用既有逻辑 C2 关系而不生成独立外传关系。
- T1011：retain。保留经不同网络介质/接口绕开主要企业出口观察面的父语义；Bluetooth 只作实现证据。
- T1052：adapt。要求数据写入可携介质后发生断开、保管和物理接续；仅插入或本地暂存不准入。

## 正式子技术

- T1020：跨组件待发交接；原路径保持型复制外传。前者按对象状态和组件谱系分类，不按周期，避免重复 NJT-0155；后者按新增复制边与 collector receipt 分类，不继承 T1020.001 名称。
- T1048：角色偏离协议出口；协议语义载荷伪装；检查不透明替代传输。三者分别改变批准路径/角色、协议事务内可区分特征和检查点可解释性，检测数据与缓解动作不同。
- T1041：控制回路内嵌外传。持久 socket 续用因来源不能证明同一传输会话稳定设计而 defer。
- T1011：独立路由次要接口外传；近距对等接收外传。两者分别依赖接口/路由到企业外和邻近 peer/session 接收，不按蜂窝或 Bluetooth 产品名分类。
- T1052：跨观察域离线接续外传；宿主不可见介质区域外传。两者分别改变跨主机/跨区保管谱系和宿主可枚举介质区域。

## 延迟与裁剪

- T1048 的“受害服务拉取式外传”具有稳定方向变化，但不稳定地依赖“替代协议”父语义，并与 NJT-0134 暂存、后续 T1567 和战术级 Niji 原生缺口相交。本批 defer，待 T1567/T1537 后作战术级 gap review；不创建 NJS、Claim、Analytic 或应用。
- T1048 加密密钥类型被合并为检查点可解释性，不创建对称/非对称兄弟项。
- T1011 独立路由轴缺少公开 Enterprise 实战案例，正式置信度保持 medium；NIST 与 ATT&CK 支持风险/观察差，不能写成已观察案例。
- T1052.001 解析为父级 USB 实现，不继承名称；ProjectSauron 和 USBStealer 支持 Niji 两轴。
