# TA0011 首批准入、分类与共享库收敛

固定范围为 ATT&CK Enterprise 19.1 的 TA0011。当前批次只处理 T1001 与 T1008；两名 sub-agent 分别提交证据和分类研究，主 Agent 在两份交接结束后才作正式决议与 ID 分配。ATT&CK 子项数量和名称仅保存在研究记录，不进入正式 NJT/NJS。

## T1001 Data Obfuscation — adapt

准入保留其 C2 通信遮蔽核心，但把正式对象限制在消息或服务会话中可见表征与真实控制语义的差。Mandiant 对 SUNBURST 的原始逆向支持可选 junk bytes、XML GUID 命令提取和 OIP 式 JSON；Unit 42 对 RDAT 支持 BMP 载体处理，但入站命令未获现场观察。正式 NJS-0152-001 根据真实控制字节与可丢弃字节的比例和位置划分，NJS-0152-002 根据声明的产品服务契约与真实 C2 功能的差划分。两者分别需要帧解析和服务画像差分。

第三条候选轴“控制语义载体分离”有父级证据，但其内外提取和摘要谱系与 TA0005/NJS-0115-003 高度重合，因此保留为 NJT-0152 父级适用情形，允许并列归类，不增设同义 NJS。T1132 的编码、T1573 的加密、T1071 的应用协议和 T1572 的隧道各有独立直接对象；单个 User-Agent 仿真与 NJS-0114-004 对照。正式 DET-000163/NJA-000174/000175 与 MIT-000150 分别处理帧恢复、服务契约和软件出口约束，不复制 NJT-0115 的通用内容规范化。

## T1008 Fallback Channels — adapt

准入要求同一植入、旧 C2 路径失败或受控触发、备用路径启用，以及后继控制交换。ClearSky DustySky 与 Cisco Talos TinyTurla 支持失败后端点选择；Unit 42 QUADAGENT 与 ISMAgent 支持 Web 失败后 DNS 后备。NJS-0153-001 保持协议而更换端点，重点修复单目的地关联；NJS-0153-002 跨协议日志面，重点连接 Web 失败、DNS 后继和端点结果。匿迹收益只在防守方目的地分组或日志面有相应关联缺口时成立，来源不证明真实告警阈值被绕过。

T1104 处理阶段/功能分工，T1568 处理地址动态求解，T1090 处理代理转发，NJT-0124 处理防火墙策略变化；正常重试、CDN、灾备及软件镜像切换均为反例。可信服务后备和长延时/DGA 变体尚无足够触发与独立观察差证据，留在研究层。DET-000164/NJA-000176、DET-000165/NJA-000177 与 MIT-000151 分别覆盖同协议端点谱系、跨协议日志关联和主备路径统一处置。

## 共享库决议

- `extend` REF-000230：沿用 Sysmon 官方 URL，补充 Event 3、22 的字段说明，不新建同源 REF。
- `reuse` REF-000431：只用于载体遮蔽和客户端指纹相邻边界；CASE-000153 是另一活动，不能充当 SUNBURST 或 RDAT 案例。
- `create` REF-000625–637、CLM-000746–753、CASE-000199–202、DET-000163–165、NJA-000174–177、MIT-000150–151：逐一核查 URL 或语义身份后建立。Zeek 文档仅支持字段可用性，样本报告不外推检测成功率。
- `split` 与既有 NJT-0115/NJS-0115-003 的内容表示对象，以及既有 DET-000112 的通用内容恢复目标；本批防御以 C2 会话、失败触发、目的地与协议日志面为单位。
- `defer` RDAT 未现场观察的入站命令、服务信誉后备、延时和 DGA 切换独立子项、通用阈值与未验证的漏报率。

父级与四个子项逐字段对照 NJT-0001 的职责：定义与直接目的、匿迹痕迹和残余、纳入/排除/正常反例、场景、攻防能力与传感器、因果机理、来源层级及研究限制均已分别写入双语自然段。两个候选没有沿用共同威胁模型或同文限制；子项防御按各自关联键与控制面区分。正式对象维持 `review`，人工领域评审尚未记录。
