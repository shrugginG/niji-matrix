# BATCH-TA0011-001 Command and Control 首批研究与集成约束

## 基线与范围

`matrix.yaml` 固定 MITRE ATT&CK Enterprise 19.1。TA0011 的 18 个父候选和 27 个 ATT&CK 子项已从官方 19.1 STIX 清单登记在 `program-inventory.md` 与 `planning/tactics/TA0011.yaml`。当前正式 TA0011 矩阵为 0 NJT、0 NJS。本批仅处理 T1001 Data Obfuscation 与 T1008 Fallback Channels；两项涉及通信表征与通信可用性，需分别研究并统一判断边界。两项均不预设准入或正式子项数量，前一批次门禁不适用。当前批次未通过证据、分类、双语内容、针对性防御、质量、Bundle 和 Web 门禁前，不开始下一批正式写入。

## 父技术边界

| 候选 | 直接行为对象 | 需检查的边界 |
|---|---|---|
| T1001 | 对命令控制通信承载数据的外观、结构或量形进行有意变换 | 与 T1132 编码、T1573 加密、T1071 应用协议选用和 T1572 隧道区分；TA0005/NJT-0115 已覆盖通用内容表示遮蔽，须证明 C2 消息或会话观察单位的独立边界，不能仅凭编码或加密另建技术 |
| T1008 | 主要 C2 路径失效或不可达时的备用通信路径与切换行为 | 与 T1104 多阶段通道、T1568 动态解析、T1090 代理及一般网络重试区分；不能仅凭多个目的地断言备用通道 |

## 子技术与证据门禁

T1001 有三个 ATT&CK 子项 T1001.001、T1001.002、T1001.003，按噪声附加、隐写和协议伪装等实现方式区分。本批须至少检验两条不同的 Niji 匿迹轴，并逐项记录 ATT&CK 子项覆盖决议。T1008 没有 ATT&CK 子项，仍须开放搜索稳定的攻击者可控切换变量。ATT&CK 子项只供研究，不导入正式 NJS；正式子项须有独立证据证明行为设计、痕迹变化、防守观察差异、兄弟边界和防御价值。来源仅支持父行为时不外推子项或防御结论。

每个候选需独立完成 retain、adapt 或 exclude 准入，再分配正式 ID。父/子双语正文按 NJT-0001 的字段责任与论证深度审查，重点检查残余痕迹、正常相似行为、攻击者能力、传感器与保留窗口，以及结论层级限制。检测须明确可用日志字段、关联窗口、误报和盲区；缓解须说明针对具体通信行为的应用及限制。脚本只作清单提取、序列化、分配、构建和验证，不生成正式论证正文。

## 并行研究与共享库

两名 sub-agent 各研究一个父候选，使用 T1001 与 T1008 专属暂存文件和临时键，只提交证据、准入建议、原生分类与防御建议，不分配 ID、不修改正式矩阵或共享库。主 Agent 等待两份结果后，统一检查 T1001/T1008 与相邻技术的边界，并用 `library_lookup.py` 及共享目录决定 reuse、extend、create、split 或 defer。可能复用的对象包括 ATT&CK 固定版本参考、网络流量/代理/DNS 遥测的既有 DET/NJA，以及出站控制类 MIT；标题相似不构成复用依据。未获结论级证据的流量形态或切换策略只保留在研究记录。

人工领域评审前，所有通过门禁的正式对象保持 `review`，不标记 `published`。
