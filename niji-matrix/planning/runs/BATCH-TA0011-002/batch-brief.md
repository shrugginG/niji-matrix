# BATCH-TA0011-002 Application Layer Protocol 研究与集成约束

## 基线与交付范围

`matrix.yaml` 固定 MITRE ATT&CK Enterprise 19.1；TA0011 的 18 个父候选已完整登记于 `planning/tactics/TA0011.yaml`。上一批 BATCH-TA0011-001 已通过逐候选证据、分类、双语正文、针对性防御、`make quality`、两项 Bundle、Web 测试 89/89 和中文英文页面检查，正式内容保持 `review` 等待人工领域评审。本批只处理 T1071 Application Layer Protocol，单候选成批：其五个 ATT&CK 子项跨 Web、文件传输、邮件、DNS 和发布/订阅，协议实现、观察面与相邻技术边界复杂，不因单候选而降低证据与内容深度。候选准入可能是 retain、adapt 或 exclude，不预设 NJT/NJS 数量；本批未完成前不进入第三批正式写入。

## 父技术直接对象与边界

T1071 的父行为锚是攻击者用应用层协议在植入和控制端之间交换指令或结果，以利用目标环境已有协议流量与允许路径。研究必须证明攻击者控制的应用会话特征如何改变可见痕迹、防守可区分性或关联成本，不能把 HTTP、DNS、SMTP 或 MQTT 等协议名称本身当作匿迹变量。正式分类需与 T1095 非应用层协议、T1102 Web Service 的服务提供者/资源使用、T1572 协议隧道的内层会话封装、T1132 数据编码及 T1573 加密区分。已有 NJT-0152 关注 C2 消息表征与服务契约伪装，NJT-0153 关注失败触发的主备路径切换；T1071 若仅重复二者的变量，应跨技术复用或收敛，不增设同义 NJS。正常浏览、解析、邮件收发、文件传输、事件订阅和产品遥测均为相似行为，需要进程、批准服务、消息方向及后继控制结果辨别。

## ATT&CK 子项仅作研究广度先验

固定版本包含 T1071.001 Web Protocols、T1071.002 File Transfer Protocols、T1071.003 Mail Protocols、T1071.004 DNS、T1071.005 Publish/Subscribe Protocols。研究者须把这五项按实现/行为维度编制覆盖决议，并至少检验两条性质不同的候选 Niji 匿迹轴，例如通信角色/发起条件与观察面/关联结构；不得按五种协议一一复制为 NJS。某个协议簇若只提供父级 C2 行为或与 T1102、NJT-0152 等相邻对象重合，应明确记录 `parent-core`、`adjacent-technique`、`evidence-deferred` 或 `not-stealth-distinct`。每个拟正式 NJS 要有跨协议或跨实现可稳定控制的变量、痕迹变化、兄弟边界、结论级证据及差异化防御。

## 证据、内容与防御门禁

ATT&CK 19.1 父级对象锚定行为与战术映射，不自动支持新子项、匿迹机理、检测字段或缓解效果。优先使用原始样本/事件分析、权威协议或产品日志文档，逐条区分现场观察、样本能力和按传感器模型推断的匿迹效果。正式父子双语字段逐项对照 NJT-0001：定义、可见与残余痕迹、纳入排除及正常反例、应用场景、攻击者/防守方模型、因果机理、证据与限制。检测建议必须给出可获得的数据字段、关联键、窗口、误报与盲区；缓解必须说明控制措施、对具体对象的应用和失败条件。未知本地流量基线不得伪装为实测阈值。

## 研究分工与共享库

一名 sub-agent 独立负责 T1071 的证据、retain/adapt/exclude 建议、原生 taxonomy 和防御设计，仅写 `planning/runs/BATCH-TA0011-002/T1071-*` 暂存材料，不分配正式 ID、不改正式矩阵或共享库。主 Agent 在交接后统一复核 NJT-0152/NJT-0153、NJT-0115、T1102 等边界，使用现有 catalog 和 `library_lookup.py` 逐项决议 reuse、extend、create、split 或 defer，再分配 ID 和写入。可能共用的现有来源包括 REF-000625（固定 STIX）、REF-000632/634/635（Zeek HTTP/连接/DNS 字段）及 REF-000230（Sysmon）；现有 DET/NJA/MIT 只有检测目标、数据与控制动作确实同义时才扩展。人工领域评审前正式对象仅可到 `review`。
