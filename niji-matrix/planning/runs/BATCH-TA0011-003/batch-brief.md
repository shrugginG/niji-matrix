# BATCH-TA0011-003 五候选研究与集成约束

## 基线、范围与批次规模

`matrix.yaml` 固定 MITRE ATT&CK Enterprise 19.1。TA0011 的 18 个父候选已经完整登记，前两批 NJT-0152、NJT-0153 和 NJT-0160 均通过证据、原生分类、双语内容、针对性防御、`make quality`、Bundle 和 Web 门禁并保持 `review`。本批按用户明确要求处理五个连续父候选：T1090 Proxy、T1092 Communication Through Removable Media、T1095 Non-Application Layer Protocol、T1102 Web Service、T1104 Multi-Stage Channels。这是允许的上限批次，扩大规模的理由是一次性收敛“路径中介、离线传递、协议层级、服务资源和阶段分工”之间的边界；每个候选仍由独立 sub-agent 研究，分两轮完成，逐候选准入、证据、分类和防御门禁不合并。候选数不保证 NJT 或 NJS 数量，本批未完全通过前不开始下一批正式写入。

## 候选直接对象与批内边界

| 候选 | 直接行为对象 | 必须收敛的兄弟与既有边界 |
|---|---|---|
| T1090 | 通过一个或多个中间网络节点转发 C2，改变受害端、最后跳点与真实控制基础设施的路径关系 | 与 NJT-0160 的应用协议 broker/解析器中介、T1102 的服务资源、T1572 的内层协议封装、NJT-0153 的失败换路区分；代理链长度、入口/出口位置和路由归属不能直接等同 NJS |
| T1092 | 借可移动介质在联网与隔离/受限主机之间异步转移命令和结果 | 与 TA0001/TA0008 既有可移动介质入口和传播对象、T1105 文件到达、物理交付以及普通文件复制区分；C2 往返和跨隔离边界是必要条件 |
| T1095 | 使用非应用层 OSI 协议或原始传输实现主机与控制端/受控主机通信 | 与 NJT-0160 的真实应用事务、T1571 非标准端口、T1572 协议隧道、T1205 流量信令区分；ICMP、UDP、raw socket 等协议名不是 NJS 边界 |
| T1102 | 借既有合法外部 Web 服务的内容、API 或资源中继 C2 | 与 NJT-0160 的协议事务拓扑、T1090 的通用路径代理、NJT-0152 的服务契约伪装、T1568 动态解析区分；服务品牌与 ATT&CK 的 dead-drop/单双向子项不得直接复制 |
| T1104 | 为不同条件、阶段或功能设置多个 C2 通道并在操作链中组合使用 | 与 NJT-0153 的失败触发备用通道、T1102 多个服务资源、T1090 多跳代理以及单一通道内的请求响应阶段区分；必须证明阶段/功能分工和观察差，而非仅存在多个地址 |

跨候选允许同一事件并列归类，但一个 Niji 子项必须由一个稳定、攻击者可控的匿迹变量拥有。主 Agent 在全部五份交接后统一裁决同义轴、父级核心与相邻归属。

## ATT&CK 子项与原生分类门禁

T1090 有四个固定基线 ATT&CK 子项（Internal Proxy、External Proxy、Multi-hop Proxy、Domain Fronting），T1102 有三个（Dead Drop Resolver、Bidirectional Communication、One-Way Communication）；两者必须至少研究两条性质不同的候选匿迹轴并逐项记录覆盖决议。T1092、T1095、T1104 没有 ATT&CK 子项，仍需开放搜索，不能因零子项而停在第一个变量。ATT&CK 子项仅作实现/行为广度先验，正式 NJS 必须有稳定变量、痕迹变化、防守观察差、兄弟边界、前提场景、独立证据和差异化防御。工具、产品、介质、协议名、端口、目标或消息字段都不能单独构成分类。

## 证据与内容深度

每个候选先作 retain、adapt 或 exclude，完成前不分配正式 NJT/NJS。固定 ATT&CK 页面只锚定父行为和战术映射；机理、子项、检测字段、控制效果和案例结论须由原始样本/事件分析、标准或权威实施文档支撑。明确区分样本能力、实验演示、现场观察与传感器模型推断。父级和所有保留子项逐字段对照 NJT-0001，完整覆盖定义、匿迹特性、残余痕迹、纳入/排除/正常反例、应用场景、攻击者与防守者模型、因果机理、证据和限制；五个候选不能共享只替换名称的威胁模型或限制段落。

Detection Strategy/Analytic 必须给出候选特有的数据源、原始到规范字段映射、关联键、窗口、可观测信号、误报、盲区与调优。Mitigation 必须给出可实施 Measure 以及每个目标的 use、expected effect 和 limitations。没有服务端日志、物理介质谱系或跨跳路径时必须降低结论，不以理论可观测性冒充部署可用性。

## 并行研究和共享库所有权

第一轮 sub-agent：T1090、T1092、T1095；第二轮：T1102、T1104。每名 sub-agent 只写 `planning/runs/BATCH-TA0011-003/<ATTACK-ID>-*` 暂存文件，使用唯一临时键；不分配正式 ID，不修改正式矩阵、战术计划或任何共享库。主 Agent 等待全部五份交接后，再统一处理 admission、跨技术边界、共享对象的 reuse/extend/create/split/defer、正式 ID、YAML 写入及验收。

共享库查询先关注既有 REF-000625（固定 19.1）、NJT-0152/0153/0160 及其 DET/NJA/MIT、可移动介质相关跨战术对象、网络路径与 DNS/HTTP/端点字段文档。名称或 “proxy/C2/egress” 词汇重合不构成复用；检测目标、数据、关联和控制动作必须同义。人工领域评审前正式对象保持 `review`。
