## 跨技术所有权

### T1105 与 NJT-0130

T1105 与 T1570 共用目标侧独立文件实际到达结果门，区别只是来源位于外部/C2 还是内部受害主机。来源拓扑改变请求、响应、writer 和授权数据，却不改变父行为。因此复用 NJT-0130，泛化名称、定义、范围、威胁模型和证据，`classification.tactic_refs` 增加 TA0011，保留创建设计 `DEC-TA0008-T1570`，新增 `DEC-TA0011-T1105` 指向同一 NJT。内部 SMB 继续使用 DET-000139/NJA-000143/MIT-000127；外部入站另建 DET/NJA/MIT。无证据的中继源间接化、同步客户端代写和刻意低速分批保持 deferred，不强制新增 NJS。

T1071 拥有持续应用事务，T1102 拥有服务对象控制资源，T1132 拥有传输中可逆表示，T1104 拥有多通道角色交接；它们可以与文件到达并列，但不替代目标文件创建/修改结果。

### T1132 与 NJT-0115/NJT-0152

T1132 作为 TA0011 父行为保留：直接对象是 C2 命令或结果在传输中的可逆表示，以及规范化前后的语义差。算法、标准/非标准标签、Base64/hex/custom alphabet 和层数不形成原生子项。可逆表示变量由跨战术 `NJS-0115-001` 唯一拥有；恢复链充分时并列归类。只有额外噪声、跨字段稀释、载体分离或服务契约伪装成立时，才并列 NJT-0152。密码机密性归 T1573。正式 taxonomy 为 `none-justified`。

防御复用：DET-000112 扩展 T1132 主体及证据；NJA-000100 的逻辑、数据、窗口和调优不变，直接复用并在规划中记录 C2 部署映射；MIT-000113 仅增加父级 Application。DET-000163/MIT-000150 不作全局扩展。

### T1205 跨战术复用

NJT-0120 已直接覆盖信号输入、matcher 状态、隐藏→激活状态转变和后继监听/反向或入站控制会话；NJS-0120-001/002 以跨事件保存状态与单包内容匹配区分，已经是 Niji 原生变量。TA0011 新增独立 adapt 决策，父级 `tactic_refs` 增加 TA0011，保留 founding `DEC-TA0005-T1205`。TA0011 结果门要求后继可重复 C2 会话、监听或命令功能；只维持持久化、Wake-on-LAN 或一次本地任务不能计入 TA0011。

新增 cd00r 原始代码来源和案例以补强 NJS-0120-001 的有序 SYN→inetd root shell 证据；REF-000453/CASE-000170 扩展到 NJS-0120-002 的 BPFDoor 魔术包→bind/reverse shell/重定向证据。DET-000117、NJA-000105/126、MIT-000118 复用并扩展证据/数据映射，不新建防御对象。

### T1219 原生三轴

- **未批准控制端命名空间重绑定**：合法工具或服务 provider 保持不变，攻击者把 endpoint 重新绑定到未批准 tenant/account/relay/workspace/controller。与 T1102 的一般服务资源不同，本项要求可交互远控产品会话及控制命名空间变化。
- **批准工作流脱离的受信远控会话**：工具、控制端甚至账号可合法，但会话未连接批准的 ticket、发起者、受助用户、设备、时间和用途。与 NJT-0152 服务契约伪装不同，本项是控制工作流授权差；与 T1133 入口不同，本项从工具会话建立及控制结果开始。
- **带外远控观察置换**：远控硬件或独立管理平面把键盘/视频/鼠标控制置于主机 OS/EDR 之外，需 BMC/KVM/固件审计和物理/网络资产关系。硬件型号不是变量。

T1219.001/.002/.003 只作覆盖证据，不复制为 NJS。MIT-000155 和 DET-000094 分别处理既有会话所有权转换、会话状态/风险情境，数据和结果门不同，不扩展。

### T1568 原生三轴

- **解析应答端点轮换**：同一逻辑名称的当前 DNS 应答集合/TTL 使植入实际连接的 C2 地址随时间轮换；必须连接 query/answer、endpoint consumption 和后继 C2。
- **共享状态定位符生成**：植入与基础设施共享词表、种子、时钟或组合状态，在运行时生成候选 locator 并选择实际可用 C2；不按 DGA 名称或算法拆分。
- **解析响应参数合成**：植入从 DNS/解析响应字段提取位或字节，并按公式合成实际 C2 IP/port/参数；必须证明合成值被连接使用。

NJT-0153 只拥有失败触发换路；NJT-0209 拥有服务对象状态；NJT-0210 拥有通道角色交接；NJT-0160 拥有 DNS 等应用事务承载；NJT-0206 拥有中介转发/路由权威。普通 CDN、DDNS、服务发现、容灾和合法短 TTL 是反例。
