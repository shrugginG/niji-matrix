# BATCH-TA0011-005 最后五候选研究、集成与战术闭合约束

## 基线与范围

`matrix.yaml` 固定 MITRE ATT&CK Enterprise 19.1。TA0011 的 18 个父候选已完整登记，前四批 13 个父候选已完成准入、正式内容、防御、Bundle 和 Web 门禁并保持 `review`。本批处理剩余五项：T1571 Non-Standard Port、T1572 Protocol Tunneling、T1573 Encrypted Channel、T1659 Content Injection、T1665 Hide Infrastructure。按用户要求使用五候选上限，分两轮由每名 sub-agent 独立研究一个父技术。五项共同收敛端口—协议关系、内外层协议、加密可检查性、流内内容注入及基础设施扫描/路由暴露边界；逐候选证据、准入、分类、内容和防御门禁仍分别执行。候选数不保证五个新 NJT。

本批通过后还必须完成 TA0011 的全量候选对账、Niji-native gap analysis、跨 18 个父候选 taxonomy/防御/共享库收敛和战术关闭记录。未人工领域评审前，正式内容和计划只能到 `review`，不能 `published` 或冒充人工批准的 complete。

## ATT&CK 子项和开放式分类

固定基线中 T1573 有 T1573.001/.002；其余四项无 ATT&CK 子项。对称/非对称仅是密码实现广度，不直接成为 NJS。零子项候选仍须从端口解析、封装关系、密钥/恢复边界、注入位置、选择性暴露/研究者差分等方向开放搜索。正式子项必须有稳定变量、痕迹变化、防守观察差、兄弟/相邻边界、前提、独立证据和差异化防御。协议、端口、算法、工具、服务、目标类别、厂商和基础设施类型不能单独分类。

## 证据、内容与防御门禁

固定 ATT&CK 页面只锚定父行为与战术映射。子项、机理、检测字段、缓解效果和案例结论优先使用原始样本/事件分析、协议/密码标准及权威产品日志文档，并区分现场观察、样本能力、实验复现和传感器模型推断。父级与正式子项逐字段对照 NJT-0001，完整覆盖定义、匿迹特性、残余痕迹、范围/反例、场景、攻防模型、机理、证据与限制，不共享换名模板。

DET/NJA 必须写出原始到规范字段映射、关联键、窗口、误报、盲区和调优；MIT 必须给出可实施 Measure 和逐目标 Application。缺少协议解析、内外层关联、密钥/恢复证据、注入前后差分或基础设施请求/响应对照时必须降低结论。
