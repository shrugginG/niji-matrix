# BATCH-TA0042-001 子技术分类修复约束

## 修复原因

上一轮中央集成人为采用“每项父技术只保留一个最强子技术”的统一裁剪，造成不受规范支持的数量对称。正式规则允许零个或多个子技术，数量只能由稳定行为、独立因果链、防守边界和证据决定。

## 本轮规则

- 不设最小、最大或统一子技术数量。
- 不因修复而强行恢复所有研究候选；仍逐项通过 candidate gate。
- 不继承 ATT&CK 子技术，也不按资源媒介或工具类型拆分。
- 与父级核心或既有 NJS 同义的候选不新建；证据不足者继续 defer。
- 所有新增子技术必须补充双语正文、原子 Claim、来源、检测/缓解引用和兄弟边界。
