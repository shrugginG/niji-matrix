# BATCH-TA0043-004 研究与收敛约束

## 基线与范围

- 战术：TA0043 Reconnaissance / 目标侦查
- ATT&CK domain：enterprise-attack
- ATT&CK version：19.1
- 候选：T1592、T1589
- 本批次重开发 Active Scanning 之后的两个父候选，不改变固定基线，也不代表 TA0043 已完成人工领域审查。

## 父技术边界

| 候选 | 直接信息或行为对象 | 与兄弟候选和既有技术的边界 |
|---|---|---|
| T1592 | 攻击前获得的主机、设备、平台和端点属性 | 人员和账户属性归 T1589；网络命名、拓扑和边界属性归 T1590；攻击者直接向目标发送端口、服务或协议探测归 NJT-0001 |
| T1589 | 攻击前获得的具体人员、账户和数字身份属性 | 抽象岗位和组织职责归 T1591；直接诱导人员披露归 T1598；凭证猜测、填充、成功重置或账户接管属于后续访问行为 |

## 子技术规则

- 不读取或导入 ATT&CK 原子技术作为 Niji 子技术分类。
- T1592 子技术按观测主体、采集是否增加独立事件以及客户端是否执行附加枚举来划分，不按硬件、软件、固件或配置字段划分。
- T1589 子技术按主要采集痕迹是否位于受害域外，以及主动请求是否拟态为正常身份事务来划分，不按凭据、邮箱或姓名等身份字段划分。
- 公开资料、第三方平台或正常协议请求不自动构成匿迹；必须证明其改变受害方可观察性、事件可区分性、关联成本或归因能力。
- 低速、多来源或来源代理化不在本批次重复建立分类；相应执行变量应与 NJT-0001 组合表达。
- 所有正式父子对象使用 schema version 2.0.0 和成对双语自然段，生命周期保持 review。

## 开发安排

- 本批次由主 Agent 直接完成两个候选的研究收敛、共享对象决议、ID 分配与规范写入，不派生并行 canonical writer。
- 候选研究记录保存在本批次目录，任何临时键在正式写入前解析为 reuse、extend、create、split 或 defer。

## 收敛注意事项

- 第三方主机观测只有在实际替代攻击者对目标的直接探测时才成立；后续重新验证仍归 NJT-0001。
- 请求固有元数据采集与嵌入式客户端枚举必须按是否新增客户端属性读取和回传严格分界。
- 受害域外身份获取与身份工作流拟态推断按遥测域和事件外观分界，不把正常公开资料访问或合法失败登录直接判为恶意。
- 暂不把匿名账户、缓存快照、低速查询或多提供方分散查询写成子技术；现有证据不足以证明这些变量被有意用于释痕。
