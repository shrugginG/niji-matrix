# BATCH-TA0043-005 研究与收敛约束

## 基线与范围

- 战术：TA0043 Reconnaissance / 目标侦查
- ATT&CK domain：enterprise-attack
- ATT&CK version：19.1
- 候选：T1590、T1591、T1598、T1593、T1594
- 本批次处理 NJT-0032 与 NJT-0033 之后的五个父候选；候选数量不保证正式技术或子技术数量，批次完成也不代表 TA0043 已完成人工领域审查。

## 子技术规则

- 不读取或导入 ATT&CK 原子技术作为 Niji 子技术分类。
- T1590 按原始观测主体和查询是否经过受害者控制面划分，不按 DNS、证书、IP 或拓扑字段拆分。
- T1591 只保留能证明目标外画像拼接改变受害方可见性的稳定实现；正常访客拟态若更直接属于 T1594，则不得在两个父技术下重复。
- T1598 按身份与话术、交互节奏、受信账户痕迹和技术承载面等稳定实现变量复核，不按媒介拆分。
- T1593 与 T1594 按第三方开放访问面和受害者自有访问面分界；公开读取本身不自动构成匿迹。
- 每项子技术必须建立行为设计、痕迹变化、防守观察影响和匿迹效果的完整因果链，并具有独立检测或缓解意义。
- 所有正式父子对象使用 schema version 2.0.0、父级自包含 NJS 编号和成对双语自然段；生命周期保持 review。

## 收敛注意事项

- T1590 的第三方传感观测与 NJT-0032 第三方主机观测必须按网络级信息对象和端点级信息对象分界；检测逻辑相同时优先扩展共享 DET/NJA。
- T1591 的目标外组织画像若只体现公开访问通道而没有组织信息特有痕迹变化，应由 T1593 承载访问表面，不为父技术强制建立重复子技术。
- T1598 的可信账户、对话节奏和承载面可以组合，但每个子技术必须有独立可观测差异；信息获取必须是直接结果。
- T1593 的假名研究账户必须有账户隔离和归因效果的直接证据；普通匿名浏览、缓存使用和多平台查询继续 defer。
- T1594 仅保留普通访客语义和受害者已发布导航工件替代猜测式枚举；路径猜测、错误差异探测与表单诱导均排除。
