# BATCH-TA0043-006 研究与收敛约束

## 基线与范围

- 战术：TA0043 Reconnaissance / 目标侦查
- ATT&CK domain：enterprise-attack
- ATT&CK version：19.1
- 候选：T1681、T1682
- 本批次处理 TA0043 最后两个非排除候选；T1596 和 T1597 已有 exclude 决策，不为满足数量建立正式技术。
- 候选数量不保证正式技术或子技术数量；只有准入、分类、证据、防御、Bundle 和 Web QA 全部通过后，TA0043 才可进入机器完成、待人工审查状态。

## 父技术边界

| 候选 | 直接信息或行为对象 | 与既有技术的边界 |
|---|---|---|
| T1681 | 对攻击者自身或相关同业的暴露、检测、归因和威胁声誉反馈，并据此调整后续可观测特征或资源选择 | 获取受害者数据按 NJT-0032 至 NJT-0035 分类；一般安全知识学习没有自身/同业暴露评估与后续调整闭环时排除 |
| T1682 | 公共 AI 对公开材料进行实质聚合、推理、转换或生成，并替代攻击者直接目标或逐源查询 | 输出信息对象仍归 NJT-0032 至 NJT-0035；直接开放内容、受害者网站和信息诱导分别归 NJT-0037、NJT-0038、NJT-0036；本地或私有模型排除 |

## 子技术规则

- 不读取或导入 ATT&CK 原子技术作为 Niji 子技术分类。
- T1681 子技术按反馈后的稳定调整变量划分：已暴露可观测特征轮换，与基于威胁声誉的候选资源门控；不按厂商、IOC 类型或来源开放性拆分。
- T1682 只有在公共 AI 实质替代原始查询并改变实际消费者痕迹位置时才成立；仅使用 AI 提高写作或搜索效率不构成子技术。
- 每项机理必须完整说明行为设计、痕迹变化、防守观察影响和匿迹效果，并保留服务商侧账户、查询、提示、响应、工具调用或声誉审计等残余痕迹。
- 受害者侧不可见不等于不可检测；Detection Strategy 必须明确服务商、威胁情报或跨阶段关联视角。
- 所有正式父子对象使用 schema version 2.0.0、父级自包含 NJS 编号和成对双语自然段，生命周期保持 review。

## 收敛注意事项

- T1681 必须具备“反馈获取 → 暴露判断 → 行动调整”的闭环，仅读取报告不纳入；特征轮换与资源门控可以组合但防守观察不同。
- T1682 必须有 AI 的实质语义贡献和查询替代；服务商仍能看到提示、响应、工具调用和账户关系，因此父级机理置信度需按公开证据校准。
- T1681 的快速轮换可能产生时空释痕，但其核心子技术变量仍是反馈触发的特征替换；T1682 暂不把提示词伪装、匿名账户或多平台查询分散写入正式分类。
- 完成本批次后复核十二个固定父候选、十个正式技术、两个 exclude 决策、所有共享对象和 Niji 原生缺口，人工 reviewers 仍为空时不得标记 published 或 complete。
