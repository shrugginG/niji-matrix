# BATCH-TA0112-002 T1686 研究与收敛约束

本批继承 matrix.yaml 的 enterprise-attack 19.1 基线。总体范围仍是 TA0112 的 18 个父候选；本次用户要求继续的五个候选按已登记的顺序为 T1686、T1484、T1666、T1689、T1600，但本交付批次只处理 T1686。上一批 T1685 已通过结论级证据、内容深度、共享库、质量、Bundle 与中英文 Web 门禁；本批未过门禁前，不开始下一批正式写入。候选数不保证正式 NJT/NJS 数。

T1686 的直接对象是攻击者控制的系统防火墙有效策略与实际流量裁决，而非防火墙品牌、配置命令或网络连接本身。研究必须证明原本应被阻断或审计的流量因攻击者变更而得到不同裁决；普通管理放行、故障切换、动态服务发现和经批准的应急变更是反例。T1685 负责安全工具及遥测功能，T1599 负责网络边界桥接，T1205 负责信号触发，普通 C2 和横向移动由各自战术负责。即使它们使用相同防火墙对象，也不得以结果相似为由重复建模。

ATT&CK 19.1 的 T1686.001、T1686.002、T1686.003 分别是云、网络设备与 Windows 主机实现，仅作 taxonomy 广度先验。至少研究两个 Niji 匿迹轴：整体防火墙姿态下降、选择性规则例外、策略 NAT/重定向所造成的可见入口与真实服务错位，以及临时开口后回滚。正式子项须由稳定可控变量、痕迹变化、观察差异、独立证据和有意义的防守实现共同支持，不导入 ATT&CK 子项、不按平台、端口或工具划分。

来源方面先查重固定 T1686 页面、BPFDoor 原始分析、UNC3886 的 TABLEFLIP 事件、Windows 防火墙 4946/4947/4948 官方事件字段和云/网络设备规则审计文档。已有 MIT-000118 是网络信号触发面治理，除非控制概念和措施完全一致，不得直接套用；已有 NJT-0123 的工具健康分析不能代替规则前后态与网络结果。共享候选只允许 reuse、extend、create、split 或 defer，ID 在准入与分类收敛后由主 Agent 分配。

本批研究交接使用 planning/runs/BATCH-TA0112-002/T1686-handoff.yaml，taxonomy 记录使用 taxonomy-breadth-review.yaml，最终结果使用 integration-summary.yaml。每个正式父子项按 NJT-0001 字段责任独立撰写成对双语自然段，检测必须恢复策略版本、规则命中与真实流量裁决，缓解必须说明规则控制权、变更验证与回滚限制。脚本只执行序列化、ID、校验和构建，不按名称替换生成正文。人工评审前仅允许 review。
