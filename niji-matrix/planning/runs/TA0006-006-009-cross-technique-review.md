# TA0006 第 9–13 项跨技术边界与共享库收敛

本轮五项均裁决 `adapt`，但直接对象不同：T1621 生成 challenge，T1111 取得 MFA proof/generator state，T1040 从不改路的网络观察面取得凭据流量，T1003 从 OS 认证权威/存储/复制服务提取材料，T1528 取得应用 access/refresh token。一个事件可以多标签，任何对象都不能用另一个对象的结果补齐自身完成点。

## 关键边界

- T1621 challenge 创建或用户批准不证明 T1111 的 MFA 材料被截获；T1111 的证明被接受也不反推攻击者生成了 challenge。
- T1111 与 NJT-0169/NJS-0093-003/NJT-0136 可在输入、认证组件或中继路径证据独立成立时并列；T1111 只拥有 MFA 证明材料与未来证明生成能力。
- T1040 保持原目的地不变；任何主动改变路径、信任指向或服务目标均归 NJT-0136。端点 packet observation 与函数参数/应用对象内秘密复制分属 T1040 和 NJT-0169/NJS-0093-003。
- T1003 以 OS 认证材料为对象；应用 token 归 T1528，普通保管库秘密归 NJT-0147，未受保护散落秘密归 T1552。非活动存储视图可与 NJT-0108 并列，但介质路径不证明凭据结果。
- T1528 的取得与 T1550/NJT-0061 的呈现、接受和资源访问分开。签发服务正常并不证明接收者合法，后继 API 使用也不证明具体取得路径。

## 正式分类与暂缓

正式建议共 13 项 NJS：T1111 两项、T1621 两项、T1040 三项、T1003 三项、T1528 三项。暂缓 T1111 绑定认证器代理、T1040 共享介质监听、T1003 低量/输出加密轴，以及所有只按产品、协议、平台、材料格式或厂商命名的候选。

所有研究交接在正式 ID 分配前完成；主 Agent 统一负责共享对象扩展，避免把同一来源、case、strategy、analytic 或 mitigation 复制为换名对象。
